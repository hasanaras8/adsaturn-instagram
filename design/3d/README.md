# 3D marka gezegeni

`scene.html` logodaki kırık yörüngeli gezegeni three.js ile render eder. Açı ve konum URL parametreleriyle değişir.

    cd design/3d && npm i && python3 render.py cikti.png "w=2160&h=2700&dist=11.5&camy=1.2&offy=0.27&offx=0.12&tiltx=0.28&tiltz=-0.42&spin=0&key=1.9&bloom=0.75&glow=1.35"

`slides.html` metinleri bu görsellerin üzerine yerleştirir (Outfit + Instrument Serif italik, tek vurgu rengi #ffb45e).
